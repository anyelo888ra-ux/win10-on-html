### win10-on-html

Un simulador web interactivo de la interfaz de Windows 10 construido utilizando tecnologías web nativas (HTML, CSS y JavaScript). Este entorno virtual se ejecuta completamente desde el navegador en cualquier dispositivo sin requerir descargas ni instalaciones. 

### Características incluidas

* Escritorio personalizado con imagen de fondo en alta definición (wallpaper.jpg).
* Iconos de sistema interactivos ("Este equipo" y "Papelera de reciclaje") cargados de forma local, con selección con un clic y apertura mediante doble clic rápido.
* Menú de inicio dinámico con diseño oscuro traslúcido y lista de aplicaciones.
* Menú contextual personalizado para el clic derecho que bloquea el menú por defecto del navegador e incluye la función de "Actualizar" con parpadeo visual.
* Ventanas flotantes múltiples que se pueden arrastrar libremente por el escritorio y cambian su orden de profundidad (se ponen al frente) al hacerles clic.
* Aplicación de Bloc de Notas completamente funcional donde puedes escribir texto real desde tu teclado.
* Reloj digital en la barra de tareas que sincroniza la hora (AM/PM) y la fecha exacta de tu dispositivo en tiempo real.
* Botón de energía simulado que ejecuta una pantalla negra de apagado y reinicia el sistema automáticamente tras 3 segundos.

### Tecnologías utilizadas

* HTML5: Estructura limpia y semántica de los componentes del sistema.
* CSS3: Estilos fieles a Windows 10, posicionamiento absoluto y efectos de desenfoque.
* JavaScript (Vanilla JS): Control total del DOM, lógica de arrastre (drag & drop), eventos del mouse y actualización del reloj del sistema.
